# Anvil

Mobile browser music studio. Songs stay on this device unless you send a clip to your own MVSEP, Treblo, or Neural Analog account.

## Pack paths

- **Extract.** One MVSEP Demucs4 HT separation. Slices drum hits, 808 notes, and short stabs into a private SFZ.
- **Restyle.** One Treblo cover of the song, then one MVSEP pass. Closer mode restyles a single stem.
- **Repair.** MVSEP, then Neural Analog debleed or denoise on those stems.

Producer style is the recipe. API keys stay in the browser. Packs are not shared.

## Run

```bash
npm install
npm run dev
```

Open the local preview and use the Split tab.
